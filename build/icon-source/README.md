# Network Checkup icons

The Network Checkup icon in the Checkup family style: a slate network picture with the green check badge that every Checkup app shares.

## Assets
Drop these into a WinUI project's `Assets` folder. The names match the Visual Studio template.

- `AppIcon.ico` holds 16, 20, 24, 32, 40, 48, 64 and 256 px. Point `<ApplicationIcon>` in the .csproj at it.
- `Square150x150Logo.scale-200.png`, `Square44x44Logo.scale-200.png`, `Square44x44Logo.targetsize-24_altform-unplated.png`, `StoreLogo.png`, `LockScreenLogo.scale-200.png`, `Wide310x150Logo.scale-200.png` and `SplashScreen.scale-200.png` are the package logos, on a transparent background.

## png
The same images as the .ico, one PNG per size.

## source
- `app-icon.svg` is the full drawing, used for 32 px and up.
- `app-icon-small.svg` is the simpler drawing with a bigger badge, used for 16, 20 and 24 px.

Badge green: gradient #3CD3B4 to #0D8A73. Slate: #71819A to #2F3B4E (small drawing #8695AC to #3A475B).
